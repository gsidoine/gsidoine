### Topological Posterior Predictive Checks — PyMC

A contribution to [`pymc-devs/pymc-examples`](https://github.com/pymc-devs/pymc-examples) exploring how **persistent homology** can be incorporated into Bayesian posterior predictive checking.

The notebook uses topological summaries to detect structural model misspecification that may be invisible to conventional low-order posterior predictive diagnostics.

→ [Topological Posterior Predictive Checks](https://github.com/pymc-devs/pymc-examples/blob/main/examples/case_studies/topological_posterior_predictive_checks.ipynb)

### [`zero-forcing-separator-algebras`](https://github.com/gsidoine/zero-forcing-separator-algebras) — Graph Theory

Research companion repository for **_Separator algebras and transfer theory for the zero-forcing polynomial_**.

The work develops finite separator algebras and exact transfer methods for the zero-forcing polynomial, combining structural graph theory with symbolic and computational verification. The repository contains the manuscript, reference implementations, exact certificates, independent verification scripts, and reproducibility material.

→ [Repository](https://github.com/gsidoine/zero-forcing-separator-algebras)  
→ [Archival release (Zenodo)](https://doi.org/10.5281/zenodo.23183837)

### [`the-scottish-book`](https://github.com/gsidoine/the-scottish-book) — Collaborative Mathematical Problem Discovery

An open mathematical notebook inspired by the **Scottish Book** tradition, exploring whether **human–AI collaboration can formulate original and substantial mathematical problems** across number theory, combinatorics, graph theory, probability, topology, and discrete geometry.

The project brings together problem formulation, mathematical proofs, computational experiments, formal verification, counterexamples, and systematic literature reviews. Each problem is developed with careful distinctions between conjectures, established results, computational evidence, and historical novelty.

Contributors are welcome to propose new problems, challenge existing formulations, submit proofs or Lean formalizations, and participate in the tradition of symbolic mathematical rewards.

→ [The Scottish Book — GitHub repository](https://github.com/gsidoine/the-scottish-book)  
→ [Browse the mathematical problem book](https://gsidoine.github.io/the-scottish-book/)  
→ [Propose a mathematical problem](https://github.com/gsidoine/the-scottish-book/issues/new?template=propose-problem.yml)
